# 本地模型：每次下载一个、测完删除

脚本：`D:\benchmark\local_benchmark\evaluate_local.py`。Python 3.10 及以上，仅标准库，无需 pip 安装。
题库：1087 道清洗候选题；`evaluation_inputs.jsonl` 给模型，`answer_key.jsonl` 只用于评分。
这是候选题库上的作答测评，答案尚未经过专家逐题核验。

本项目文件集中在 `D:\benchmark\local_benchmark`：

```text
local_benchmark/
  evaluate_local.py          测评脚本
  start_ollama.ps1           使用本项目 models 目录启动 Ollama
  本地模型测评说明.md
  data/
    evaluation_inputs.jsonl  1087 道题目和选项，不含答案
    answer_key.jsonl         对应答案，仅评分器读取
  models/                   模型权重（通过项目启动脚本下载时存放于此）
  results/                  各模型测评结果
  tests/                    程序测试
```

## 历史科目

历史题库为用户提供的 `usable_text(2).jsonl`，共 1140 道单选题，保存在 `data/history/`。
`source.jsonl` 是原文件副本；`evaluation_inputs.jsonl` 仅含题目编号、题干和选项；`answer_key.jsonl` 仅供评分；`manifest.json` 记录来源、数量及文件哈希。
接入时仅做结构校验和字段映射，保持原题、选项顺序和答案不变；未重新核验历史事实、答案正确性或缺图依赖，原数据中的 usable_text 标记不等于完成新的人工审定。

历史试跑（复用已下载的模型，不需要重复下载）：

```powershell
cd D:\benchmark\local_benchmark
python .\evaluate_local.py --subject history --model qwen3:1.7b --limit 5
```

历史全量，自动跳过已完成题目：

```powershell
python .\evaluate_local.py --subject history --model qwen3:1.7b
```

历史结果单独保存到 `results/历史/qwen3_1.7b/`；提示词使用“初中历史”。其他本地模型只需替换 `--model`。不加 `--subject history` 时仍然测道德与法治，原有命令和续跑结果兼容。
同一块显卡建议一次只测一科，等道德与法治跑完或 Ctrl+C 暂停保存后，再启动历史测评。

校验历史数据（不调用模型）：

```powershell
python .\evaluate_local.py --subject history --check-only
```

## 地理科目（纯文本子集）

地理数据来自 `GeoBench_初中地理_中文完整版.zip` 的 `data/questions_benchmark_ready.jsonl`。
原包共 1200 题，其中 968 题有结构化答案；这 968 题中 783 题为图文题、185 题为纯文本题。
当前模型与脚本只测文本，因此接入 185 题，不把缺失图像的题目混入文本成绩；232 道缺答案题也不纳入。
只生成 `data/geography/evaluation_inputs.jsonl`、`answer_key.jsonl`、`manifest.json`，未解压 PPT、统计表或嵌套的大型原始压缩包。

共用材料与子题题干拼接，已有表格文字原样保留，选项仅去掉原文本开头重复的 A．/B．等编号，选项顺序和答案不变。
答案文件记录原题号、题组和来源。原包答案通过截图 OCR 加规则提取，虽标记为高置信度，仍不等同于逐题专家审定。
本次结果只能表述为地理纯文本子集成绩，不能代表整包 1200 题或地理读图能力。

先试跑 5 题：

```powershell
cd D:\benchmark\local_benchmark
python .\evaluate_local.py --subject geography --model qwen3:1.7b --limit 5
```

然后运行全部 185 题，自动跳过已完成题目：

```powershell
python .\evaluate_local.py --subject geography --model qwen3:1.7b
```

结果保存在 `results/地理/qwen3_1.7b/`。现有模型无需再次下载；每次只运行一个科目的测评。

仅校验地理数据，不调用模型：

```powershell
python .\evaluate_local.py --subject geography --check-only
```

数据文件是原清洗输出的逐字节副本，原始清洗输出仍保留。脚本按自身所在目录定位数据和结果，不依赖终端当前目录。

为了让模型权重也保存在这个子文件夹中，先从任务栏托盘退出已有的 Ollama 应用，并停止已有的 `ollama serve`。在终端一运行：

```powershell
cd D:\benchmark\local_benchmark
powershell -ExecutionPolicy Bypass -File .\start_ollama.ps1
```

保持终端一打开，在终端二执行下面的下载和测评命令。启动脚本仅为该服务进程设置模型目录，不修改全局环境变量，不自动搬运或删除 C 盘已有模型。

## 第一个模型：Qwen3 1.7B

先按上面的方式启动本项目 Ollama 服务，再在另一个 PowerShell 中执行（仅下载这一个，约 1.4GB）：

```powershell
Set-Location 'D:\benchmark\local_benchmark'
ollama pull qwen3:1.7b
python .\evaluate_local.py --model qwen3:1.7b --limit 5
```

先检查 5 题试跑的耗时、格式错误和截断数量。确认流程可用后执行全量；已有的前 5 题自动跳过：

```powershell
python .\evaluate_local.py --model qwen3:1.7b
```

如 `python` 不可用，可改用 `D:\benchmark\.venv\Scripts\python.exe`。
若无法连接 Ollama，按上面的方式运行 `start_ollama.ps1` 并保持该窗口打开。
若提示端口已占用，先退出已有的 Ollama 应用/服务后重新运行项目启动脚本，确保模型进入本项目的 models 目录。

确认 `summary.json` 中 `full_dataset` 和 `complete_without_api_errors` 均为 true 后，再删除这个模型：

```powershell
ollama stop qwen3:1.7b
ollama rm qwen3:1.7b
ollama list
```

删除模型不会删除 D 盘的题库、脚本和结果。共享模型层仍被其他模型引用时不一定释放全部下载大小。

## 结果与断点续跑

结果统一按 `D:\benchmark\local_benchmark\results\学科\模型名称\` 保存，模型名中的冒号在 Windows 文件夹名中替换为下划线。现有结果已经迁移，运行命令不变：

```text
results/
  道德与法治/
    qwen3_1.7b/
  历史/
    qwen3_1.7b/
  地理/
    qwen3_1.7b/
```

每个模型目录包含：

- `results.csv`：Excel 可打开，含题目、标准答案、模型答案、对错、状态、耗时。
- `summary.json`：题数、准确率、错误与截断数量、完成状态。
- `attempts.jsonl`：每次尝试的原始最终回答、思考内容、Token 和耗时，逐题落盘；其中历史评分字段代表当时评分，不会在重算时改写。
- `scored_results.jsonl`：每道题最近一次作答按当前规则重算的结果，与当前 CSV 和汇总一致。
- `config.json`：模型摘要、量化信息、Ollama 版本、数据哈希及生成参数。

Ctrl+C 中断后运行同一命令即可继续。接口错误会重试；已完成的正确、错误、格式不合规或截断回答不会重新生成，避免挑选有利答案。连续 3 道接口错误会停下。
不要在测评期间更新或删除当前模型，也不要同时运行两份同目录测评。进程被强制终止后若留下 `.running.lock`，确认没有测评进程运行后才删除该锁。若断电留下不完整 JSONL 尾行，脚本会明确报错，应先备份再修复尾行。

## 统一评分规则

- 每题独立请求，统一提示词；不联网、不检索，不把答案发给模型。
- 默认均请求思考模式 `--think on`；温度 0，seed 20261109，上下文 8192，总输出上限 4096 Token（包含思考）。这不保证跨硬件完全确定。
- 内容评分允许单个字母、`B. ①③`、字母后附解析、`答案是B`、`正确答案：C` 等明确结论；兼容 Markdown 加粗及大小写/全角字母。只分析最终回答，不从思考过程或解析中任意寻找字母，也不根据标准答案挑选字母。
- 多答案、前后明确结论冲突、否定答案或无法可靠提取的回答记为 `invalid`，需要检查原文；生成达到长度上限记为 `truncated`，不计正确。这是保守的规则解析器，不保证覆盖所有自然语言表达。
- `accuracy` 是内容准确率；`format_compliance_rate` 单独统计最终回答仅含一个大写 A/B/C/D 的比例。附带解析但选项正确可以得分，格式合规率不会因此提高。
- 评分版本为 `politics-answer-extraction-v2`，汇总和逐题结果中均有记录。生成提示词和参数未变，旧 `config.json` 的 protocol 字段保留原值以兼容续跑；评分规则以 scoring_protocol 为准。
- 准确率 = 正确题数 / 已尝试题数。格式错误、截断、接口失败均计入分母；未尝试题目不计入，因此中途准确率不是全量成绩。
- `--limit 5` 只是流程检查，不代表题库总体水平。全量成绩还需确认 `full_dataset` 和 `complete_without_api_errors`。
- 若截断多，可统一提高各模型的 `--max-tokens` 和 `--num-ctx`，并通过 `--output` 使用新的目录重新评测。上下文增加也会增加显存占用。
- Qwen 如需非思考对照，使用 `--think off`，并用 `--output` 指定额外目录（如 `results/历史/qwen3_1.7b/think_off`）。默认目录不再带思考模式后缀；模式与已有配置不一致时脚本会拒绝混写。不要与思考模式混合比较。
- 本地 DeepSeek 8B 是 DeepSeek-R1-0528-Qwen3-8B 蒸馏模型，不能与完整 DeepSeek 大模型混同。

仅校验数据，无需模型：
